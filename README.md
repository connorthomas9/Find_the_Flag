## Overview
In this project, we will be using Decision Trees to try and predict the continent that a flag comes from based on certain shapes and colors that appear on the flags themselves.

The primary analysis takes place in the `ftf_notebook.ipynb` Jupyter Notebook file

The dataset used for this project is the `flag.data` file, and comes by way of the `UCI Machine Learning Repository`

This project comes by way of `Codecademy.com` and has been recreated from scratch in order to demonstrate knowledge of applied usage of decision trees
